LibreVies — héroïne humaine stylisée

Rogue.fbx et rogue_texture.png proviennent du KayKit Character Pack:
Adventurers de Kay Lousberg. Le modèle est riggé et animé, et est distribué
sous licence CC0 1.0 : usage personnel et commercial autorisé.

Source : https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
Page du pack : https://kaylousberg.itch.io/kaykit-adventurers

Le modèle Rogue est utilisé comme corps humain de l'héroïne. LibreVies ajoute
une chevelure rouge stylisée dans le code afin de respecter la direction
artistique du projet.
